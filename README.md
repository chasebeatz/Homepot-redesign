# HomePot redesign

Open `index.html` in a browser, or run `node server.cjs` and visit http://localhost:4173.

A responsive, standalone rebuild using the original project's food photography. Includes live search, category and favourite filters, sorting, meal details with portion and spice selections, a persistent shopping bag, location selection, delivery/pickup totals, order review, simulated cooking and delivery tracking, order history, reordering, and star ratings with feedback.

The shared Homepot-project repository and Matthew's cart/payment/review commits informed the connected ordering flow. The rebuilt source is also staged in a separate `redesign/` folder in the local repository checkout. Existing shared pages remain intact. No GitHub changes have been pushed.

This is a front-end concept. Menus, kitchens, prices, and preparation times are illustrative. It does not process payments, send orders, authenticate customers, or connect to delivery services. Cart, favourites, demo order history, and feedback are saved in the browser. Checkout names and addresses are not saved or sent. Delivery stages advance using the demo button; they do not represent live kitchen or courier updates. Google Fonts is optional; system fonts work offline.

The original website is unchanged.
